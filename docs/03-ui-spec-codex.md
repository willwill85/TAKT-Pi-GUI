# 03 — Codex 风格 UI 规范

目标：布局、信息层级、交互、动效、质感与 **Codex 桌面版**一致（macOS 原生控件风格，而非网页风格）。
> 说明：本机未安装 Codex.app，规范依据 Codex 桌面版公开形态与截图整理；落地后用实机截图逐项校准，差异记入文末“校准记录”。

## 1. 窗口与布局

```
┌ 红绿灯 ─────────────────────────────────────────────────────────────────┐
│ ┌ 侧栏(可折叠, 280) ┐ ┌ 主区 ────────────────────────┐ ┌ 右面板(可选) ┐ │
│ │ ＋ 新线程          │ │ 工具栏：标题 · 项目/分支 …    │ │ 标签：审查 /  │ │
│ │ ⌕ 搜索  ⚙ 自动化   │ │ ───────────────────────────  │ │ 文件 / 终端   │ │
│ │ ─ 线程 ─           │ │      对话列（最大 ~760）      │ │               │ │
│ │ ▾ 项目A            │ │                              │ │               │ │
│ │    线程… 2h  +12-3 │ │   ┌ Composer（圆角卡片）┐     │ │               │ │
│ │ ▸ 项目B            │ │   └────────────────────┘     │ │               │ │
│ │ 底部：设置 / 用量   │ │                              │ │               │ │
│ └────────────────────┘ └──────────────────────────────┘ └───────────────┘ │
└─────────────────────────────────────────────────────────────────────────┘
```

- 单窗口、全高内容（`fullSizeContentView`，隐藏标题栏分隔线），红绿灯嵌入侧栏顶部。
- 侧栏：`NSVisualEffectView` material `.sidebar`（半透明毛玻璃，跟随壁纸），宽 280（可拖 220–420），⌘B 折叠。
- 主区：`windowBackgroundColor` 纯净底色；对话列居中，**最大宽 760pt**，两侧留白随窗口伸缩。
- 右面板：可拖宽 320–720，⌘⌥B 开关；顶部分段标签（Review / Files / Terminal / 子 Agent / 文件标签页）。
- 最小窗口 960×640；记忆尺寸与位置。

## 2. 设计 Token

| Token | 浅色 | 深色 |
|-------|------|------|
| 主背景 | `#FFFFFF` | `#1E1E1E`（接近 Codex 深灰，非纯黑） |
| 侧栏 | 系统 sidebar 材质 | 同 |
| 次级面（气泡/卡片/Composer 底） | `#F4F4F5` | `#2A2A2C` |
| 分隔线 | `black 8%` | `white 10%` |
| 强调色 | 系统强调色（默认蓝）；发送键为**主色圆形** | 同 |
| 文本 | `.primary` / `.secondary` / `.tertiary` | 同 |
| 代码块底 | `#F6F6F7` | `#262628` |
| Diff 增/删 | 绿 `#1A7F37` / 红 `#CF222E`，行底 12% 透明 | 绿 `#3FB950` / 红 `#F85149` |

- 字体：正文 SF Pro 14/21；侧栏 13；工具栏标题 13 semibold；代码 SF Mono 12.5/18。可在设置中改（对应 pi-web 字体设置）。
- 圆角：Composer 20；卡片 12；气泡 16；按钮/chip 8（胶囊用于 chip）；侧栏行 8。
- 间距基线 4pt；对话块间距 16；工具行间距 6。
- 动效：折叠 0.18s ease-out；新消息淡入+上移 4pt；发送键/停止键形变 0.15s；面板开合用 spring(0.3,0.9)。尊重“减少动态效果”。

## 3. 侧栏

- 顶部：**New thread**（⌘N）、**Search**（⌘K）、Skills / Automations（对应 Cron）入口，均为图标+文字的整行按钮。
- “Threads” 区：按**项目（文件夹）分组**，项目行：文件夹图标 + 名称 + 悬停显示 `＋` 与 `…`；展开显示线程。置顶线程出现在最上方“Pinned”。
- 线程行（高 30）：左侧状态（运行中=旋转小圈，待输入=橙点，未读完成=蓝点），标题单行截断，右侧相对时间（`2h`/`3d`）；悬停变为归档/置顶按钮；选中=强调色 12% 底。
- 子 Agent 会话作为线程子行缩进显示。
- 底部：头像/用量（provider usage）、**Settings** 齿轮、Remote Pi 状态点。
- 右键菜单：重命名、置顶、Fork、复制会话 ID、在 Finder 显示、归档、删除。

## 4. 主区工具栏

- 左：线程标题（可点击重命名）+ 项目名/路径 chip。
- 右：分支 chip（git 分支 + worktree 菜单）、**Open in…**（Finder/终端/编辑器）、终端开关、Review（带 `+N −M` 统计）、右面板开关、更多（导出、会话树、系统提示词…）。

## 5. 对话列

- **用户消息**：右对齐圆角气泡（次级面底色，最大宽 80%），附件缩略图在气泡上方；引用文本显示为左竖线块。
- **助手消息**：无气泡，左对齐正文（Textual Markdown）；操作条（复制、从此处 Fork）悬停显示。
- **思考**：灰色单行 “Thinking…/Thought for 12s”，点开展开全文（次级色、小号）。
- **工具调用**（核心 Codex 观感）：
  - 相邻工具调用合并为一组，折叠行：`▸ Explored 3 files, ran 2 commands`（运行时显示当前动作 + 细微 shimmer）。
  - 展开后每个调用一行：图标 + 动词短语（`Read src/a.ts`、`Ran npm test`、`Edited foo.swift +12 −3`、`Searched "xyz"`），点击展开细节（命令输出终端块、diff、参数）。
  - 文件路径渲染为可点击 chip（打开到右面板）。
  - 失败调用行用红色图标，输出自动展开。
- **本轮总结卡**：回合结束若有写文件 → “N files changed +A −B” 卡片，含 Review / Undo-less 的“Open diff”按钮。
- **工作时长**：分隔线上 “Worked for 2m 14s”。
- 错误/重试/压缩：居中的细胶囊横幅。
- 自动跟随输出；用户上滑则暂停跟随并显示 “↓ 回到最新” 浮钮。

## 6. Composer（输入卡片）

- 圆角 20 的卡片，贴底居中，宽度同对话列；多行自适应（最小 2 行，最大 ~8 行后内部滚动）。
- 顶部：附件缩略图/文件 chip 行；运行中时上方出现“排队中”条（steering / follow-up，可删/编辑）。
- 底部工具行（左→右）：`＋`（添加文件/图片）、权限/工具预设 chip、**模型选择 chip**（`claude-opus-5.5 ▾`）、**思考档 chip**（`High ▾`）、…右侧：上下文用量环、麦克风(可选)、**发送键**（强调色圆形↑；运行中变为 ■ 停止；运行中输入内容时发送=插话）。
- 卡片下方的次级行：运行环境 chip（`Local ▾` / Worktree）、分支 chip、cwd。
- `/` 弹出斜杠命令列表，`@` 弹出文件列表（均为悬浮在 Composer 上方的圆角列表，键盘↑↓/Tab/回车）。
- 拖拽文件到窗口：整窗高亮提示 “Drop to attach”。

## 7. 空状态 / 新线程

- 居中大标题 “What should we build in <项目>?”，下方 Composer；其上是项目/worktree 选择 chip；下方 3–4 个建议卡片（可选）。

## 8. 右面板

- **Review**：文件列表（状态点 + `+N −M`）+ 单文件统一 Diff（行号、增删着色、折叠上下文、文件头粘性）；顶部切换 “Unstaged / All”。
- **Files**：树 + 搜索；点击文件在标签中打开（代码/Markdown/图片/PDF/CSV）。
- **Terminal**：SwiftTerm，多标签，字体/配色跟随主题。

## 9. 设置窗口

- 独立设置窗口（⌘,），左侧图标导航，右侧表单（`Form` 分组风格）；与 Codex 设置页一致的分区：General · Models · Skills · Agents · Plugins · MCP · Automations · Projects · About。

## 10. 键盘与菜单

⌘N 新线程 · ⌘K 搜索/命令面板 · ⌘B 侧栏 · ⌘⌥B 右面板 · ⌘J 终端 · ⌘, 设置 · ⌘↩ / ↩ 发送（可配置）· Esc 停止 · ⌘⇧[ / ] 切换线程 · ⌘L 聚焦输入框 · ⌘F 在线程内查找。完整原生菜单栏（File/Edit/View/Thread/Window/Help）。
